# Juliet's Portfolio

A simple, responsive personal portfolio website for Napasiri Juliet Arkangelo Ngoni built with HTML, CSS and Bootstrap. It showcases Juliet's projects, education, contact details and social links — designed to be easy to customize and deploy (for example on GitHub Pages).

## Features
- Clean, dark-themed design with accent colors
- Hero section with profile image, intro and social links
- About section with education and biography
- Projects section highlighting small projects and systems
- Contact form UI and contact details (email, phone, WhatsApp)
- Responsive layout using Bootstrap 5
- Uses Google Fonts and Bootstrap Icons via CDN

## Technologies
- HTML5
- CSS3 (custom)
- Bootstrap 5 (via CDN)
- Google Fonts (Poppins)
- Bootstrap Icons (via CDN)

## Customization
- Update the name, biography and education in the About section.
- Replace `pic.jpg` with your profile photo; adjust size/cropping as needed.
- Update social and project links:
  - GitHub, LinkedIn, Twitter anchors in the Hero and Footer sections.
- Change colors by editing the CSS :root variables:
  - `--primary-color`, `--accent`, `--dark-bg`, `--light-text`
- To add more projects, copy a project card in the Projects section and modify its content.

## Deployment (GitHub Pages)
1. Commit and push changes to GitHub.
2. In the repository settings, enable GitHub Pages (choose the main branch and / (root) folder).
3. The site should be available at: `https://<your-username>.github.io/Portfolio-Web/` (may take a minute).

## Accessibility & Improvements
- Add alt text to images (already included for profile picture).
- Consider implementing form back-end or integrating a service (Formspree, Netlify Forms) to receive messages.
- Add keyboard-focus visible states and ARIA labels where appropriate.
- Add SEO metadata and social preview tags (Open Graph / Twitter Cards).
